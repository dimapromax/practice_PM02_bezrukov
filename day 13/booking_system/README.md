 Booking System - Сервисный слой с очередью ожидания

Описание

Система управления бронированиями отелей с поддержкой:
CRUD для отелей, номеров, бронирований
Проверка доступности номеров
Расчет стоимости с сезонными коэффициентами
Очередь ожидания (Waitlist)** - если номер занят, пользователь может встать в очередь
Уведомление пользователей при освобождении номера (Observer Pattern)



| Паттерн | Назначение |
|---------|------------|
| Repository | Абстракция доступа к данным |
| Service Layer | Бизнес-логика |
| Unit of Work | Управление транзакциями |
| DTO | Передача данных между слоями |
| Dependency Injection | Слабая связанность |
| Observer | Уведомления при освобождении номера |
| Queue | Управление очередью ожидания |
