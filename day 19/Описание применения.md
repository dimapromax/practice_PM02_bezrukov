**1 НАЗНАЧЕНИЕ ПРОГРАММЫ**

**1.1 Функциональное назначение**

Программа "Система управления бронированиями в отеле" предназначена для автоматизации процессов:



Управления бронированиями номеров



Отслеживания статусов бронирований



Проверки доступности номеров



Финансового учета



Обработки платежей



**1.2 Область применения**

Программа может применяться в гостиничных комплексах, отелях, хостелах и других объектах размещения для автоматизации процесса управления бронированиями.



**1.3 Квалификация пользователей**

Для работы с программой пользователь должен обладать:



Базовыми навыками работы с операционной системой



Пониманием структуры командной строки (для CLI)



Базовыми знаниями JSON (для работы с файлами)
