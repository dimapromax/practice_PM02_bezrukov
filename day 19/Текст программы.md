## 2 ФУНКЦИОНАЛЬНОЕ НАЗНАЧЕНИЕ

### 2.1 Основные функции

2.1.1 Управление отелями и номерами

- Создание отеля с указанием уникального идентификатора, названия и адреса
- Добавление номера с указанием идентификатора, цены за ночь, вместимости и типа номера (standard, deluxe, suite)
- Проверка доступности номеров на указанные даты

2.1.2 Управление бронированиями

- Создание нового бронирования с проверкой существования номера, доступности номера на даты и корректности диапазона дат
- Отмена существующего бронирования с проверкой статуса
- Изменение статуса бронирования: подтверждение (PENDING → CONFIRMED), заселение (CONFIRMED → CHECKED_IN), выселение (CHECKED_IN → CHECKED_OUT)

2.1.3 Финансовые функции

- Расчет стоимости бронирования с учетом сезонных коэффициентов и скидок за длительное бронирование
- Расчет общей выручки отеля за указанный период
- Создание и обработка платежей, выполнение возвратов

### 2.2 Поддерживаемые статусы

- PENDING — Ожидает подтверждения
- CONFIRMED — Подтверждено
- CHECKED_IN — Гость заселен
- CHECKED_OUT — Гость выселен
- CANCELLED — Отменено

471 | def validate_card_number(card_number: str) -> bool:
472 |     """
473 |     Проверить номер карты (алгоритм Луна).
474 |     
475 |     Аргументы:
476 |         card_number: Номер карты
477 |     
478 |     Returns:
479 |         bool: True если номер валидный
480 |     """
481 |     if not card_number:
482 |         return False
483 |     
484 |     # Удаляем пробелы
485 |     card_number = card_number.replace(' ', '').replace('-', '')
486 |     
487 |     # Проверка, что строка состоит только из цифр
488 |     if not card_number.isdigit():
489 |         return False
490 |     
491 |     # Проверка длины (13-19 цифр)
492 |     if len(card_number) < 13 or len(card_number) > 19:
493 |         return False
494 |     
495 |     # Алгоритм Луна
496 |     total = 0
497 |     for i in range(len(card_number) - 1, -1, -1):
498 |         digit = int(card_number[i])
499 |         if (len(card_number) - 1 - i) % 2 == 1:
500 |             digit *= 2
501 |             if digit > 9:
502 |                 digit -= 9
503 |         total += digit
504 |     
505 |     return total % 10 == 0

514 |         check_out: Дата выезда

539 |         7: 1.5,  # Июль
540 |         8: 1.5,  # Август
541 |         12: 1.3, # Декабрь
542 |         1: 1.1,  # Январь

548 |     """

556 |     Returns:

558 |     """
559 |     if not validate_date_range(check_in, check_out):
560 |         raise InvalidDatesError("Некорректный диапазон дат")

562 |     nights = (check_out - check_in).days

565 |     
566 |     for _ in range(nights):
