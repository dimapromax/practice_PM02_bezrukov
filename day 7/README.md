Контрольные вопросы
1. Как в Flask создать сессию и проверить её?

Ответ:

python
from flask import session
session['user_id'] = 1
if 'user_id' in session:
    print("Пользователь авторизован")
2. Почему нужно хешировать пароли? Как это сделать с помощью bcrypt?

Ответ: Хеширование защищает пароли при компрометации БД. Использование bcrypt:

python
import bcrypt
hashed = bcrypt.hashpw(password.encode('utf-8'), bcrypt.gensalt())
if bcrypt.checkpw(password.encode('utf-8'), hashed.encode('utf-8')):
    print("Пароль верный!")
3. Как работает декоратор @login_required?

Ответ: Декоратор проверяет наличие ключа user_id в сессии. Если пользователь не авторизован, выполняется перенаправление на страницу входа. Если авторизован - выполняется оригинальная функция.

4. Как реализована капча в проекте? Можно ли её обойти?

Ответ: Реализована простая текстовая капча (сложение двух чисел). Обойти можно, если знать результат, но защита предназначена от автоматических ботов, а не от человека.

5. Какие права есть у администратора? У работника?

Ответ:

Администратор - полный доступ: управление пользователями, просмотр всех данных, изменение конфигурации

Работник - ограниченный доступ: только просмотр и работа с заказами

6. Как защитить маршрут /admin/users от доступа обычного пользователя?

Ответ: Использовать декоратор @admin_required, который проверяет роль пользователя в сессии.

7. Какие команды нужно выполнить для запуска проекта на новом компьютере?

Ответ:

bash
pip install -r requirements.txt
python app.py
8. Что такое requirements.txt и как его создать?

Ответ: requirements.txt - файл со списком зависимостей. Создаётся командой pip freeze > requirements.txt.
