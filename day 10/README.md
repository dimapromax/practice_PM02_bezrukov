Спецификация сервиса валидации
Функция: validate_order(order: dict) -> dict

Входной формат:

json
{
    "order_id": 1,
    "total": 15000,
    "items": [
        {"name": "Книга", "quantity": 2, "price": 500}
    ],
    "user": {
        "id": 1,
        "created_at": "2025-01-01",
        "email": "user@example.com",
        "phone": "+79991234567"
    },
    "category": "Books",
    "age_verified": true,
    "delivery_country": "RU",
    "wallet_country": "RU"
}
Выходной формат:

json
{
    "valid": true,
    "reasons": [],
    "risk_score": 0.0
}
Бизнес-правила:

Сумма заказа > 0 и < 1 000 000

Для новых пользователей (created_at > 7 дней назад) - сумма не более 15 000

Количество позиций <= 50

Заказ из категории "Alcohol" требует age_verified = True и время 08:00-23:00

При риск-скоринге: если сумма > 100 000 → risk_score = 0.9
