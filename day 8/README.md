Контрольные вопросы
1. Какие виды программных документов определяет ГОСТ 19.101-77?

Ответ: Техническое задание, пояснительная записка, руководство пользователя, программа и методика испытаний, описание применения.

2. Из каких разделов состоит Техническое задание по ГОСТ 19.201-78?

Ответ:

Введение

Основания для разработки

Назначение разработки

Требования к программе

Требования к программной документации

Технико-экономические показатели

Стадии и этапы разработки

Порядок контроля и приёмки

3. Какие поля страницы должны быть установлены в текстовом документе по ГОСТ 2.105-95?

Ответ:

Левое поле - 30 мм (для подшивки)

Правое поле - 15 мм

Верхнее поле - 20 мм

Нижнее поле - 20 мм

4. Как оформляются номера разделов и подразделов в тексте документа?

Ответ: Разделы нумеруются арабскими цифрами без точки (1, 2, 3). Подразделы - номер раздела, точка, номер подраздела без точки в конце (1.1, 1.2).

5. Какие требования предъявляются к стилю изложения текста в техническом документе?

Ответ: Текст должен быть чётким, кратким, не допускать различных толкований. Запрещено использовать разговорную речь, техницизмы, синонимы для одного понятия.

6. Какие обязательные реквизиты должен содержать титульный лист программного документа?

Ответ: Наименование организации, гриф утверждения, наименование документа, обозначение документа, сведения о разработчике, сведения о проверяющем, город и год выпуска.
