Контрольные вопросы
1. Что такое ER-диаграмма и в чём её преимущество перед текстовым описанием БД?

Ответ: ER-диаграмма - это визуальная модель данных. Преимущества: наглядность, возможность согласования с заказчиком, автоматическая генерация корректного SQL-кода, визуализация связей между таблицами.

2. Какие типы связей существуют? Приведите пример для своего варианта.

Ответ (для Варианта 3 - Библиотека):

1:N - Один читатель может взять много книг (Читатели → Выдача_книг)

M:N - Одна книга может иметь много авторов, один автор может написать много книг (Книги ↔ Авторы через Книги_Авторы)

3. Что такое нормализация? Для чего нужна 3НФ?

Ответ: Нормализация - процесс устранения дублирования данных и аномалий. 3НФ (третья нормальная форма) требует отсутствия транзитивных зависимостей - неключевые поля не должны зависеть от других неключевых полей.

4. Как в MySQL Workbench создать связь «многие ко многим»?

Ответ: Используется инструмент N:M Relationship. Workbench автоматически создаёт промежуточную таблицу с двумя внешними ключами, ссылающимися на родительские таблицы.

5. Что означает флаг AI (Auto Increment)?

Ответ: AI (Auto Increment) - автоматическое увеличение значения при вставке новой записи. Обычно используется для первичных ключей, чтобы генерировать уникальный ID.

6. Как экспортировать ER-диаграмму в PDF?

Ответ: File → Export → Export as PNG/SVG/PDF → выбрать PDF → указать имя файла.

7. Для чего нужен внешний ключ?

Ответ: Внешний ключ (FK) обеспечивает связь между таблицами, ссылаясь на первичный ключ другой таблицы. При ON DELETE RESTRICT запрещает удаление записи, на которую есть ссылки.

8. Как импортировать данные из CSV в таблицу через Workbench?

Ответ: Кликнуть правой кнопкой на таблице → Table Data Import Wizard → выбрать CSV-файл → указать разделитель ; → сопоставить столбцы.

9. Какая команда SQL показывает все таблицы в текущей базе данных?

Ответ: SHOW TABLES;

10. Зачем сохранять SQL-скрипт и диаграмму в Git-репозитории?

Ответ: Для хранения истории изменений, возможности восстановления, совместной работы и документирования проекта.
