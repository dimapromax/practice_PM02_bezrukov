Контрольные вопросы:
1.ER-диаграмма — графическое представление структуры БД. Преимущество: наглядность, легко видеть связи между таблицами.
2.Типы связей: 1:1, 1:N, M:N. Пример для библиотеки: 1 читатель → N выдач (1:N), книги M:N читатели (через Выдача_книг).
3.Нормализация — устранение дублирования. 3НФ — все поля зависят только от первичного ключа (нет транзитивных зависимостей).
4.Связь M:N в Workbench: инструмент N:M Relationship → клик на две таблицы → автоматически создаётся промежуточная таблица.
5.AI (Auto Increment)— автоувеличение значения. Ставят на целочисленный первичный ключ (PK INT).
6.Экспорт в PDF: File → Export → Export as PDF (или Print Diagram → Save as PDF).
7.Внешний ключ — для ссылочной целостности. При ON DELETE RESTRICT — удаление запрещено, пока есть дочерние записи.
8.Импорт CSV в Workbench: правой кнопкой на таблицу → Table Data Import Wizard → выбрать файл → настроить → выполнить.
9.Команда: `SHOW TABLES;`
10.Зачем в Git: контроль версий, резервное копирование, совместная работа, документация.
