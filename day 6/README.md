Контрольные вопросы
1. Зачем нужен параметр auto_increment в конфигурации столбца?

Ответ: AUTO_INCREMENT автоматически генерирует уникальное значение при вставке новой записи, что гарантирует уникальность первичного ключа без необходимости ручного ввода.

2. Что произойдёт, если в INSERT не указать значения для NOT NULL полей?

Ответ: Будет ошибка (Error 1364: Field 'поле' doesn't have a default value), так как NOT NULL требует явного значения при вставке.

3. Как в Tkinter получить выделенную строку из Treeview?

Ответ:

python
selected = self.tree.selection()
if selected:
    values = self.tree.item(selected[0])['values']
4. Почему мы не даём пользователю редактировать поле с первичным ключом?

Ответ: Потому что первичный ключ должен быть уникальным и неизменным идентификатором записи. Редактирование PK может нарушить целостность данных и связи с другими таблицами.

5. Как защитить приложение от SQL-инъекций?

Ответ: Использовать параметризованные запросы с %s плейсхолдерами:

python
cursor.execute("SELECT * FROM users WHERE login = %s", (login,))
